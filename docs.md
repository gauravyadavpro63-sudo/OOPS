What is OOPs?
OOPs stands for Object-Oriented Programming.

It is a programming approach in which we organize code around objects rather than writing everything as separate functions.

CLASS--> Blueprint
OBJECT--> Instance of class

#Padding 
Padding is extra, unused memory that the compiler inserts between data members or at the end of a structure/class to satisfy memory alignment requirements.


. The four pillars of OOPs
These are the four core concepts you'll study.


1. Encapsulation

Keeping data and the functions that operate on it together, while controlling access to the data.

Example: protecting a bank account's balance.




2. Abstraction

Hiding unnecessary implementation details and exposing only what someone needs to use.

Example: driving a car without knowing exactly how its engine works.



3. Inheritance

Creating a new class based on an existing class, allowing it to reuse or extend behavior.

Example: Car and Bike inheriting shared features from Vehicle.




4. Polymorphism

Allowing the same interface or operation to produce different behavior depending on the context.

Example: different vehicle classes implementing their own start() behavior.
