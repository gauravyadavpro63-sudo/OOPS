# 🧩 Object-Oriented Programming (OOP) in C++

This repository documents my learning journey, from basic OOP fundamentals to understanding how object-oriented principles are used to write structured, reusable, and maintainable code.

- Classes & Objects
- Constructors & Destructors
- Default and Parameterized Constructors
- Copy Constructors
- `this` Pointer
- Static Data Members & Functions
- Encapsulation
- Abstraction
- Inheritance
- Types of Inheritance
- Polymorphism
- Function Overloading
- Operator Overloading
- Function Overriding
- Virtual Functions
- Friend Functions & Classes
- Access Specifiers
- `const` Keyword
- Pointers & Dynamic Memory Allocation
